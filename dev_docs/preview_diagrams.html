project_overview.md 解析フロー

sequenceDiagram
    participant User as ユーザー
    participant Script as Pythonスクリプト
    participant Model as EMPeaksモデル
    
    User->>Script: データ(x, y)をロード
    Script->>Model: モデル初期化 (K=3など)
    Script->>Model: fit(x, y) を実行
    loop EMアルゴリズム
        Model->>Model: E-step (確率計算)
        Model->>Model: M-step (パラメータ更新)
        Model->>Model: 収束判定
    end
    Model-->>Script: フィッティング完了
    Script->>Model: plot(x, y)
    Model-->>User: グラフ表示

api_reference.md fitメソッド フローチャート

flowchart TD
    Start[開始] --> Init[初期値設定
(sampling等)]
    Init --> LoopStart{収束ループ}
    LoopStart --> EStep[E-step: 所属確率の計算]
    EStep --> MStep[M-step: パラメータ更新]
    MStep --> CalcLL[尤度(Log-Likelihood)計算]
    CalcLL --> Check{収束判定
(変化 < r_eps?)}
    Check -- No --> LoopStart
    Check -- Yes --> End[終了]
